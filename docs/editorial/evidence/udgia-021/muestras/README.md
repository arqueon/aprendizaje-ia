# UDGIA-021 — estado interno de la muestra pública

Este directorio contiene prototipos de lectura, no páginas integradas al sitio.

## Recuperabilidad y continuidad

- La muestra `aprendizaje-hibrido.md` menciona las Orientaciones y la futura guía para el
  profesorado, pero no las presenta como enlaces porque aún no existe un destino público
  canónico para ambas referencias.
- La entrada general menciona las Orientaciones y las guías como marco del recorrido, pero
  solo enlaza tres páginas que ya existen. Los destinos directos de las fuentes canónicas se
  resolverán en el contrato de rutas antes de cualquier integración.
- El cierre conserva únicamente dos destinos que ya existen en Hugo: aprendizaje activo y
  SAMR/ICAP.
- Las cinco muestras de continuidad ya recibieron el lote editorial local aprobado el
  2026-08-02; los destinos públicos heredados todavía no han sido modificados. La columna se
  evalúa como un recorrido de seis páginas, no como piezas aisladas.
- La integración queda bloqueada hasta resolver destinos canónicos, actualizar la columna y
  recibir evaluación separada y VoBo humano.

| Muestra local | Destino público que nombra | Estado interno |
|---|---|---|
| `entrada-general.md` | Co-creación, aprendizaje activo y Bloom/diseño inverso | Muestra local refinada; destinos públicos heredados |
| `cocreacion.md` | Aprendizaje activo | Muestra local normalizada; destino público heredado |
| `aprendizaje-activo.md` | Aprendizaje híbrido | Muestra local normalizada; destino público heredado |
| `aprendizaje-hibrido.md` | Aprendizaje activo y SAMR/ICAP | Muestra local normalizada; destinos públicos heredados |
| `samr-icap.md` | Bloom/diseño inverso | Muestra local normalizada; destino público heredado |
| `bloom-diseno-inverso.md` | Guía docente y regreso a SAMR/ICAP | Cierre local aplicable; la guía no tiene ruta pública y el regreso existe |

Las seis muestras nombran Orientaciones y guía para explicar su función en el ecosistema,
pero no inventan enlaces mientras no exista una ruta pública canónica. Esta limitación bloquea
la integración de la columna, no la evaluación aislada de cada texto.

Este registro pertenece al expediente interno y no debe copiarse al artefacto público.
