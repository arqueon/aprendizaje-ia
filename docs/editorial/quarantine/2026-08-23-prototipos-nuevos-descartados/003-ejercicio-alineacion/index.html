Para docentes que preparan una actividad

Tres formas de revisar la misma actividad

Usa la misma instrucción en las tres opciones y elige cuál te ayuda mejor a escribir un cambio que puedas usar en clase.

La situación

Una actividad para la próxima clase

Una docente de primer semestre prepara una actividad para la próxima clase. Quiere que el grupo compare dos fuentes y explique su decisión. Esta es la instrucción que escribió:

Lee dos resúmenes y elige cuál fuente es mejor. Puedes usar IA para ayudarte.

La frase no dice qué debe comparar el grupo, qué hará la IA ni qué razones deberá entregar.

Al terminar cada opción: tendrás una instrucción revisada y una pregunta para comprobar si otra persona entiende qué hará el grupo.
