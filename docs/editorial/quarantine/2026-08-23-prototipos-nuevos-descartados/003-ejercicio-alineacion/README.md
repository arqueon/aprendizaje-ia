# Tres prototipos para revisar una actividad

Prototipos desechables para sustituir una miniaplicación rechazada por falta de claridad y coherencia visual.

## Meta común

En menos de cinco minutos, una persona docente debe producir una frase que pueda incorporar a una actividad real.

## Comparación

| Dimensión | Una decisión | Antes y después | Semáforo |
|---|---|---|---|
| Acción central | Reescribir una parte | Comparar y adaptar | Diagnosticar y priorizar |
| Qué te llevas | Ficha antes/después | Frase revisada | Primer cambio que harás |
| Grado de guía | Medio | Alto | Bajo |
| Carga inicial | 110 palabras | 140 palabras | 114 palabras |
| Mejor para | Persona con una frase propia | Primera aproximación | Revisión rápida |

**Recomendación:** `una-decision`. Conserva el valor diagnóstico, pero obliga a producir una mejora concreta y no a completar un cuestionario largo.

Ningún prototipo está integrado ni publicado en el sitio.
