## Variante: Antes y después

### Design stance
Aprender por contraste antes de adaptar el patrón a una actividad propia.

### Key choices
- Layout: dos versiones comparadas y una transferencia posterior.
- Typography: jerarquía editorial consistente con el sitio.
- Color: papel, tinta, almagre y oliva.
- Interaction: identificar qué mejora y escribir una frase equivalente para la actividad.

### Trade-offs
- Strong at: explicar sin introducir categorías abstractas.
- Weak at: la pregunta de opción correcta añade una barrera antes de producir.

### Best for
- Personas que necesitan un ejemplo completo antes de revisar una actividad propia.
