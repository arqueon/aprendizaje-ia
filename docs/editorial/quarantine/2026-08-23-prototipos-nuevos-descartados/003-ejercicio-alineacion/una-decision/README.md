## Variante: Una decisión

### Design stance
Un solo problema, una sola reescritura y una ficha antes/después.

### Key choices
- Layout: columna editorial con tres pasos numerados.
- Typography: serif para jerarquía y sans serif para instrucciones.
- Color: papel, tinta, almagre y oliva del piloto editorial.
- Interaction: elegir un problema y generar una ficha antes/después.

### Trade-offs
- Strong at: transferencia inmediata a una actividad real.
- Weak at: requiere llegar con una frase de la actividad; el ejemplo reduce esa barrera.

### Best for
- Docentes que ya tienen una actividad y quieren corregir una parte.
