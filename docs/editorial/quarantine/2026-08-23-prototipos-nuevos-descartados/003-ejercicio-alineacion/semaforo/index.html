La situación

Una actividad de primer semestre

Una docente de primer semestre prepara una actividad para la próxima clase. Quiere que el grupo compare dos fuentes y explique su decisión.

Instrucción inicial:

Lee dos resúmenes y elige cuál fuente es mejor. Puedes usar IA para ayudarte.

Responde las tres preguntas pensando solamente en esa frase.

Al terminar: tendrás el primer problema que conviene atender y una frase con el cambio que llevarías a clase.

1. ¿La entrega incluye una comparación, explicación, decisión o procedimiento?
Debes poder leer o revisar cómo llegó el grupo a la respuesta.
2. ¿El grupo ensaya antes el mismo trabajo que entregará?
Antes de entregar no realiza una tarea distinta.
3. ¿La ayuda deja al grupo la comparación, comprobación o decisión?
Puede orientar o hacer preguntas, pero no hace ese trabajo por la persona.
