{{< lead >}}
Una conversación completa no explica por sí sola qué aprendiste. Esta bitácora conserva las decisiones que cambiaron el trabajo sin obligarte a entregar datos privados ni páginas de transcripción.
{{< /lead >}}

## Plantilla

| Momento | Nota breve |
|---|---|
| Propósito inicial | ¿Qué intentabas comprender, crear o decidir? |
| Punto de partida | ¿Qué idea, borrador, método o criterio ya tenías? |
| Ayuda solicitada | ¿Qué tarea delimitada pediste a la IA? |
| Aporte útil | ¿Qué pregunta, alternativa o señal cambió tu atención? |
| Descarte | ¿Qué no aceptaste y por qué? |
| Comprobación | ¿Qué fuente, dato, prueba o persona consultaste? |
| Transformación | ¿Qué cambiaste con criterio propio? |
| Pendiente | ¿Qué incertidumbre permanece? |
| Declaración | Herramienta, propósito, partes afectadas y responsabilidad humana. |

## Qué no registrar

No copies datos personales, información confidencial ni transcripciones completas si no son necesarias. Describe la decisión y conserva por separado solo la evidencia autorizada.

## Criterio de avance

La bitácora sirve cuando otra persona puede distinguir tu punto de partida, el aporte de la IA, la comprobación y tu decisión final. No se evalúa por cantidad de prompts.
