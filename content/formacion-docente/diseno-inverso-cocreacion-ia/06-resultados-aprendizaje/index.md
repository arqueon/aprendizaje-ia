Decir que el grupo debe «comprender» un tema no permite saber todavía qué hará ni qué evidencia mostrará su aprendizaje. Un resultado observable nombra una acción, el contenido sobre el que se realiza, las condiciones relevantes y el criterio que permitirá valorar el desempeño.

## ¿Qué es un resultado de aprendizaje observable?

Un resultado de aprendizaje observable describe lo que el estudiante será capaz de hacer al finalizar una actividad o curso. No se trata de lo que el docente enseñará ni del contenido que se revisará, sino de una acción concreta, visible y evaluable por parte del estudiante.

El resultado necesita expresarse mediante un desempeño que pueda observarse en un producto, una actuación o una decisión. Esto permite explicar qué se valorará y comprobar si la evidencia corresponde al propósito; la justicia de la evaluación también depende de los criterios, las condiciones y los apoyos disponibles.

La siguiente pauta ayuda a precisar resultados observables. No es una fórmula que garantice objetividad: cada resultado todavía debe revisarse frente al contexto, el propósito formativo y las condiciones de evaluación.

{{< proceso >}}

{{< paso titulo="Identificar el verbo observable" >}}

Elige un verbo que denote una acción concreta y medible, como analizar, explicar, resolver o diseñar. Evita verbos vagos como conocer o comprender.

{{< /paso >}}

{{< paso titulo="Definir el objeto o contenido" >}}

Especifica sobre qué se realizará la acción: un concepto, un problema, un caso, una habilidad, etc.

{{< /paso >}}

{{< paso titulo="Establecer la condición o contexto" >}}

Indica bajo qué circunstancias, recursos o limitaciones se espera el desempeño. Por ejemplo: utilizando datos reales, en un entorno simulado, con apoyo de una herramienta digital.

{{< /paso >}}

{{< paso titulo="Determinar el criterio de calidad o éxito" >}}

Define cómo se sabrá que el resultado es satisfactorio: precisión, pertinencia, número de evidencias, claridad en la argumentación, etc.

{{< /paso >}}

{{< /proceso >}}

{{< idea titulo="Síntesis del proceso" >}}
Un resultado observable integra verbo + objeto + condición + criterio. Ejemplo: "El estudiante será capaz de analizar el riesgo de dos comunidades ante una ola de calor, relacionando amenaza, exposición, vulnerabilidad y capacidad de respuesta, y justificar cuál enfrenta mayor riesgo mediante al menos tres datos del caso."
{{< /idea >}}

## La taxonomía de Bloom revisada: especificando el nivel cognitivo

La taxonomía revisada de Bloom ofrece un vocabulario para conversar sobre el proceso cognitivo que pide un resultado: recordar, comprender, aplicar, analizar, evaluar o crear. El verbo orienta esa conversación, pero no determina por sí solo la complejidad real de la tarea.

Seleccionar un verbo y contrastarlo con la actividad ayuda a comprobar si la evidencia exige el proceso cognitivo buscado. El verbo aislado no basta: «analizar» puede encabezar unas instrucciones que en realidad solo piden repetir una lista.

## Niveles cognitivos en la taxonomía de Bloom revisada

Explora cada nivel para conocer sus características, verbos asociados, ejemplos de resultados y tipos de evidencia recomendada.

{{< pestanas >}}

{{< pestana titulo="Recordar" >}}

Este nivel implica recuperar información previamente aprendida, como hechos, términos o definiciones. Los verbos típicos son identificar, enumerar, reconocer y definir.

Ejemplo de resultado: "El estudiante identificará los componentes del modelo X." Evidencia: cuestionario o listado.

{{< /pestana >}}

{{< pestana titulo="Comprender" >}}

Aquí el estudiante construye significado a partir de la información, explicando, resumiendo o ejemplificando conceptos. Verbos frecuentes: explicar, resumir, comparar, clasificar.

Ejemplo: "El estudiante explicará cómo la vulnerabilidad influye en el riesgo climático." Evidencia: explicación escrita o mapa conceptual.

{{< /pestana >}}

{{< pestana titulo="Aplicar" >}}

Consiste en utilizar conocimientos o procedimientos en situaciones nuevas o conocidas. Verbos: resolver, emplear, ejecutar, demostrar.

Ejemplo: "El estudiante aplicará el modelo X para resolver un caso práctico." Evidencia: ejercicio resuelto o demostración.

{{< /pestana >}}

{{< pestana titulo="Analizar" >}}

Implica descomponer información en partes, identificar relaciones o estructuras. Verbos: distinguir, organizar, inferir, contrastar.

Ejemplo: "El estudiante analizará los factores de riesgo en un caso de estudio." Evidencia: análisis causal o matriz comparativa.

{{< /pestana >}}

{{< pestana titulo="Evaluar" >}}

Supone emitir juicios fundamentados con criterios y evidencias. Verbos: valorar, justificar, criticar, priorizar.

Ejemplo: "El estudiante evaluará dos propuestas de intervención y justificará su elección." Evidencia: dictamen o debate argumentado.

{{< /pestana >}}

{{< pestana titulo="Crear" >}}

En este nivel, el estudiante produce una respuesta o solución original. Verbos: diseñar, formular, desarrollar, proponer.

Ejemplo: "El estudiante diseñará una estrategia de prevención y justificará cada componente." Evidencia: proyecto o prototipo.

{{< /pestana >}}

{{< /pestanas >}}

{{< idea titulo="Bloom como vocabulario de procesos, no como escalera" >}}
Recordar, comprender, aplicar, analizar, evaluar y crear nombran procesos cognitivos distintos que pueden apoyarse entre sí. No forman una ruta que toda actividad deba recorrer en ese orden: una persona puede volver a recordar datos mientras evalúa una alternativa, y una tarea presentada como «crear» puede exigir poco razonamiento si solo pide combinar una plantilla. La taxonomía ayuda a precisar el proceso buscado y la evidencia correspondiente; no determina la complejidad por la posición de una palabra.
{{< /idea >}}

## ¿Cómo elegir el nivel cognitivo adecuado para mi actividad?

Seleccionar el nivel correcto es clave para que el resultado sea pertinente y alcanzable. Explora cada aspecto para tomar decisiones informadas y evitar errores frecuentes.

{{< acordeon >}}

{{< pliegue titulo="Relación con el contexto y objetivos" abierto="true" >}}

El nivel cognitivo debe responder a las necesidades del grupo, el momento del curso y los propósitos formativos. No siempre es necesario llegar a "crear"; a veces, analizar o aplicar es lo más relevante.

Ejemplo: En un curso introductorio, puede ser suficiente que el estudiante explique o aplique conceptos básicos.

{{< /pliegue >}}

{{< pliegue titulo="Vinculación con la evidencia y secuencia" >}}

El verbo elegido debe estar alineado con la evidencia que se solicitará y con las actividades previas. Si se pide evaluar, debe haber oportunidades para analizar y argumentar antes.

Tip: Revisa que la secuencia didáctica prepare al estudiante para el nivel de desempeño esperado.

{{< /pliegue >}}

{{< pliegue titulo="Riesgos de inflación taxonómica" >}}

Usar verbos de alto nivel (como "evaluar" o "crear") en tareas que solo requieren recordar o comprender genera confusión y expectativas poco realistas.

Advertencia: Ajusta el verbo al tipo de tarea y verifica que la evidencia realmente exija ese nivel cognitivo.

{{< /pliegue >}}

{{< /acordeon >}}

## Cuatro tipos de conocimiento

Además del nivel cognitivo, es fundamental identificar el tipo de conocimiento que se busca desarrollar: factual, conceptual, procedimental o metacognitivo. Esta distinción permite precisar aún más lo que se espera del estudiante y cómo se evidenciará el aprendizaje.

Al cruzar el nivel de Bloom con el tipo de conocimiento, se obtienen resultados más claros, específicos y alineados con las competencias del curso.

## Tipos de conocimiento en los resultados de aprendizaje

Explora cada tipo para conocer su definición, verbos asociados, ejemplos de resultados y evidencias habituales.

{{< pestanas >}}

{{< pestana titulo="Factual" >}}

Se refiere a datos, términos, fechas y detalles específicos. Es la base para niveles superiores de conocimiento.

Ejemplo: "El estudiante identificará los elementos clave del modelo X." Evidencia: listado o cuestionario.

{{< /pestana >}}

{{< pestana titulo="Conceptual" >}}

Incluye categorías, modelos, teorías y relaciones entre conceptos. Permite comprender estructuras y principios.

Ejemplo: "El estudiante explicará las relaciones entre amenaza, exposición y vulnerabilidad." Evidencia: mapa conceptual o explicación comparativa.

{{< /pestana >}}

{{< pestana titulo="Procedimental" >}}

Implica métodos, técnicas, algoritmos o protocolos. Se centra en el "cómo hacer".

Ejemplo: "El estudiante aplicará un protocolo para resolver un caso práctico." Evidencia: ejercicio resuelto o demostración.

{{< /pestana >}}

{{< pestana titulo="Metacognitivo" >}}

Consiste en el conocimiento y regulación del propio aprendizaje. Incluye la reflexión sobre estrategias y procesos.

Ejemplo: "El estudiante valorará la eficacia de la estrategia utilizada y propondrá ajustes." Evidencia: autoevaluación o reflexión escrita.

{{< /pestana >}}

{{< /pestanas >}}

{{< idea titulo="Cruzando niveles y tipos de conocimiento" >}}
Una matriz que cruza la taxonomía de Bloom con los tipos de conocimiento permite visualizar combinaciones posibles y diseñar resultados más completos.

Por ejemplo, se puede analizar conocimiento conceptual (comparar dos teorías), aplicar conocimiento procedimental (emplear un protocolo en un caso), o evaluar conocimiento metacognitivo (valorar la propia estrategia). Esta herramienta ayuda a diversificar y precisar los resultados de aprendizaje.
{{< /idea >}}

## Evita los verbos vagos: haz el aprendizaje observable

Uno de los errores más comunes es utilizar verbos como conocer, comprender, aprender o familiarizarse. Estos términos no indican cómo se demostrará el aprendizaje y dificultan la evaluación objetiva.

Para traducir intenciones generales en resultados observables, elige verbos que impliquen acciones concretas y medibles, como explicar, comparar, aplicar, analizar, evaluar o diseñar. Así, el aprendizaje se vuelve visible y verificable.

## Ejemplos de resultados observables por nivel y tipo de conocimiento

Explora estos ejemplos para ver cómo se formulan resultados claros, alineados y medibles en distintos niveles y tipos de conocimiento.

{{< acordeon >}}

{{< pliegue titulo="Aplicar (procedimental)" abierto="true" >}}

"El estudiante resolverá un caso de análisis de datos utilizando el modelo X en veinte minutos y alcanzará al menos 80% de precisión." Evidencia: ejercicio resuelto.

Tip: Asegúrate de que la evidencia permita verificar la aplicación del procedimiento.

{{< /pliegue >}}

{{< pliegue titulo="Analizar (conceptual)" >}}

"El estudiante distinguirá los factores estructurales e individuales presentes en un caso de desigualdad y explicará al menos dos relaciones entre ellos." Evidencia: análisis causal.

Tip: Relaciona el análisis con ejemplos concretos del contexto.

{{< /pliegue >}}

{{< pliegue titulo="Evaluar (metacognitivo)" >}}

"El estudiante valorará la eficacia de la estrategia utilizada y propondrá ajustes." Evidencia: reflexión escrita.

Tip: Incluye siempre un criterio claro para la autoevaluación.

{{< /pliegue >}}

{{< pliegue titulo="Crear (procedimental)" >}}

"El estudiante diseñará una propuesta de intervención educativa y justificará cada componente mediante evidencia pertinente." Evidencia: proyecto o plan.

Tip: Define los criterios de calidad para la propuesta creada.

## ¿Cómo puede apoyar la IA la formulación de resultados?

La inteligencia artificial puede ser una aliada para traducir intenciones generales en resultados observables, proponer versiones en distintos niveles cognitivos y detectar verbos vagos. Sin embargo, la decisión final sobre el nivel, el número y la pertinencia de los resultados siempre debe recaer en la persona docente.

Utilizar la IA de manera estratégica permite ahorrar tiempo y enriquecer las opciones, pero nunca sustituye el juicio profesional ni el conocimiento del contexto real del grupo.

Descubre cómo utilizar la inteligencia artificial para mejorar la redacción y calibración de los resultados de aprendizaje en tus cursos, siguiendo una serie de pasos prácticos y efectivos.

{{< proceso >}}

{{< paso titulo="Redactar la intención inicial" >}}

Escribe lo que deseas que el estudiante logre, aunque sea de manera general o preliminar.

{{< /paso >}}

{{< paso titulo="Solicitar a la IA reformulaciones observables" >}}

Pide a la IA que traduzca tu intención usando la fórmula verbo + objeto + condición + criterio.

{{< /paso >}}

{{< paso titulo="Pedir versiones en diferentes niveles y tipos" >}}

Solicita a la IA que proponga resultados en varios niveles cognitivos y tipos de conocimiento, junto con la evidencia correspondiente.

{{< /paso >}}

{{< paso titulo="Revisar y ajustar las propuestas" >}}

Evalúa si las propuestas son pertinentes, evitan la inflación taxonómica y se ajustan al contexto real del grupo.

{{< /paso >}}

{{< paso titulo="Validar el nivel y la pertinencia" >}}

Selecciona y adapta los resultados finales, asegurando que sean alcanzables, alineados y relevantes para tu curso.

{{< /paso >}}

{{< /proceso >}}

{{< idea titulo="Síntesis del proceso" >}}
La IA es una herramienta de apoyo, pero la validación y adaptación final siempre corresponde a la persona docente.
{{< /idea >}}

## Riesgos y controles al usar IA en la formulación de resultados

El uso de IA puede agilizar la redacción de resultados, pero también implica riesgos que deben gestionarse. Explora cada riesgo y su control recomendado.

{{< acordeon >}}

{{< pliegue titulo="Inflación taxonómica: cómo evitarla" abierto="true" >}}

La IA puede sugerir verbos de alto nivel para tareas simples. Controla que el nivel cognitivo corresponda a la tarea y la evidencia.

Tip: Ajusta o recorta los resultados si detectas desproporción entre verbo y tarea.

{{< /pliegue >}}

{{< pliegue titulo="Proliferación de resultados excesivos" >}}

La IA tiende a generar más resultados de los necesarios. Limita a uno central y uno o dos instrumentales o complementarios.

Tip: Etiqueta cada resultado según su función para facilitar la ponderación posterior.

{{< /pliegue >}}

{{< pliegue titulo="Propuestas desconectadas del contexto real" >}}

La IA puede sugerir resultados genéricos o poco pertinentes para tu grupo. Siempre revisa y adapta al contexto específico.

Tip: Proporciona a la IA información clara sobre el perfil y necesidades del grupo.

{{< /pliegue >}}

{{< pliegue titulo="Validación humana irrenunciable" >}}

Ninguna propuesta de IA debe usarse sin revisión y validación docente. La responsabilidad pedagógica es indelegable.

Tip: Considera toda propuesta de IA como un borrador hasta tu validación final.

{{< /pliegue >}}
