{{- /* Sistema global de tablas UDGPlus C. Sin atributos, una tabla de dos columnas se presenta como editorial y una de tres o más como matriz. Cuando la función semántica importa, el contenido puede declarar: {.udgia-table--comparison .udgia-table--row-headers caption="Título visible de la tabla"} Variantes admitidas: editorial, comparison y matrix. El contenido permanece como una tabla HTML real en móvil; el contenedor ofrece desplazamiento horizontal con foco. */ -}} {{- $columnCount := 0 -}} {{- with index .THead 0 -}} {{- $columnCount = len . -}} {{- end -}} {{- $declaredClasses := .Attributes.class | default "" -}} {{- $variant := cond (gt $columnCount 2) "matrix" "editorial" -}} {{- if strings.Contains $declaredClasses "udgia-table--comparison" -}} {{- $variant = "comparison" -}} {{- else if strings.Contains $declaredClasses "udgia-table--matrix" -}} {{- $variant = "matrix" -}} {{- else if strings.Contains $declaredClasses "udgia-table--editorial" -}} {{- $variant = "editorial" -}} {{- end -}} {{- $rowHeaders := strings.Contains $declaredClasses "udgia-table--row-headers" -}} {{- $caption := .Attributes.caption | default "" -}} {{- $ordinal := add .Ordinal 1 -}} {{- $positionToken := .Position | anchorize -}} {{- $tableID := printf "udgia-table-%s-%d" $positionToken $ordinal -}} {{- $captionID := printf "%s-caption" $tableID -}} {{- $hintID := printf "%s-hint" $tableID -}} {{- $regionLabel := printf "Tabla %d en %s" $ordinal .Page.Title -}} {{- with $caption -}} {{- $regionLabel = printf "Tabla: %s" . -}} {{- end -}}

Desliza horizontalmente para consultar todas las columnas.

{{- with $caption }} {{- end }} {{- range .THead }} {{- range . }} {{- end }} {{- end }} {{- range .TBody }} {{- range $cellIndex, $cell := . }} {{- if and $rowHeaders (eq $cellIndex 0) }} {{- else }} {{- end }} {{- end }} {{- end }}
